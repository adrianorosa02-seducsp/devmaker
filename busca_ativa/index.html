def criar_token_prova(usuario_id, prova_id, minutos_validade=15):
    # Gera um token hexadecimal de alta entropia
    token_seguro = secrets.token_hex(8).upper()
    
    # Define a expiração exata
    expiracao = datetime.datetime.now() + datetime.timedelta(minutes=minutos_validade)
    
    # Modelo do registro no BD
    token_data = {
        "user_id": usuario_id,
        "exam_id": prova_id,
        "token": token_seguro,
        "status": "pode_usar", # pode_usar | em_uso | utilizado | expirado
        "expires_at": expiracao
    }
    
    return token_data

2. Estados do Ciclo de Vida do Token

🟢 pode_usar

Gerado pelo aplicador e aguardando entrada do aluno dentro da janela de validade.

🔵 em_uso

O aluno iniciou a prova. Bloqueia múltiplos logins em outros dispositivos.

⚪ utilizado

A prova foi entregue com sucesso. O token é inativado permanentemente.

🔴 expirado

A janela de tempo (ex: 15min) encerrou antes da validação pelo aluno.
