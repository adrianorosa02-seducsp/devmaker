# Atividade: Escalonamento de Features com StandardScaler no Google Colab

## Estudo de Caso: Análise Imobiliária para Nova Incorporação

Uma grande incorporadora de imóveis planeja lançar um empreendimento imobiliário em uma nova região da Califórnia. Para otimizar o projeto e definir estratégias de vendas e marketing, a incorporadora precisa entender os fatores que influenciam os preços das casas na região. Eles têm acesso a um vasto conjunto de dados históricos sobre imóveis, como o **California Housing Dataset**.

**O Desafio:** As features do dataset, como `housing_median_age` (idade média das residências), `total_rooms` (número total de cômodos em um bloco censitário, não em uma única casa) e `median_income` (renda média), possuem escalas muito diferentes. Por exemplo, o número de cômodos (`total_rooms`) pode variar de centenas a milhares, enquanto a idade média da casa (`housing_median_age`) varia de 1 a 52 anos. Essa disparidade de escala pode prejudicar a performance de muitos algoritmos de Machine Learning que a incorporadora planeja usar para prever preços, segmentar o mercado ou identificar tendências.

**A Solução: Padronização com `StandardScaler`**

Para garantir que todas as features contribuam igualmente para os modelos e evitar que features com valores maiores dominem o processo de aprendizado, a equipe de análise de dados da incorporadora decide aplicar o `StandardScaler`. Ao padronizar os dados, eles garantem que as features tenham uma média de 0 e um desvio padrão de 1, tornando-as comparáveis e melhorando a eficácia dos modelos preditivos e analíticos.

## Teoria: Compreendendo o StandardScaler

Em Machine Learning no mundo real, as features frequentemente possuem escalas e distribuições muito diferentes. Escalonar as features é uma etapa de pré-processamento crucial que pode melhorar o desempenho de muitos algoritmos. O `StandardScaler` remove a média e escala para variância unitária, transformando os dados de forma que a distribuição das features tenha uma média de 0 e um desvio padrão de 1.

### Exemplo Básico com `StandardScaler` (NumPy)
Demonstração fundamental de como o `StandardScaler` da `sklearn` opera em um pequeno array NumPy, centralizando a média em 0 e escalando o desvio padrão para 1.

```python
from sklearn import preprocessing
import numpy as np

X_train = np.array([[ 1., -1.,  2.],
                    [ 2.,  0.,  0.],
                    [ 0.,  1., -1.]])

scaler = preprocessing.StandardScaler().fit(X_train)
print("Médias:", scaler.mean_)
print("Escalas (Desvio Padrão)::", scaler.scale_)

X_scaled = scaler.transform(X_train)
print("Dados escalonados:\n", X_scaled)
```

### Aplicação do `StandardScaler`
Agora, aplicamos o `StandardScaler` a essas features. Este escalonador remove a média e escala para variância unitária. O resultado é que a distribuição das features terá uma média de 0 e um desvio padrão de 1.

```python
from sklearn.preprocessing import StandardScaler
import numpy as np

# Inicializa e ajusta o StandardScaler
housing_scaler = StandardScaler()
X_housing_scaled = housing_scaler.fit_transform(X_housing)

# Converte o array escalonado de volta para um DataFrame para melhor legibilidade
X_housing_scaled_df = pd.DataFrame(X_housing_scaled, columns=features_to_scale)

print("Médias dos features:", housing_scaler.mean_)
print("Desvio Padrão dos features:", housing_scaler.scale_)

print("\nFeatures escalonados (primeiras 5 linhas):")
display(X_housing_scaled_df.head())

print("\nVerificando a média e desvio padrão dos dados escalonados (devem ser aproximadamente 0 e 1, respectivamente):")
print(X_housing_scaled_df.describe().loc[['mean', 'std']])
```
