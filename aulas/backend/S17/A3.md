## 1. Introdução ao Gerenciamento de Dependências
O gerenciamento de dependências permite que desenvolvedores integrem bibliotecas e pacotes de terceiros aos projetos back-end com eficiência, garantindo a funcionalidade, o versionamento e a compatibilidade do sistema em diferentes ambientes de desenvolvimento e produção.

## 2. Ambiente Node.js e Gerenciador `npm`

O **npm** (*Node Package Manager*) é o gerenciador de pacotes padrão para aplicações Node.js e ecossistemas JavaScript.

### 2.1. Instalação Básica do Node.js e npm
Para utilizar o `npm`, é necessário instalar o Node.js (que já inclui o gerenciador de pacotes).

* **No Linux (Ubuntu/Debian):**
  ```bash
  sudo apt update
  sudo apt install nodejs npm -y
  ```
* **Verificação da instalação:**
  ```bash
  node -v
  npm -v
  ```

### 2.2. Comandos Essenciais do `npm`

| Comando | Descrição | Exemplo de Uso |
| :--- | :--- | :--- |
| `npm init` | Inicializa um novo projeto, gerando o arquivo `package.json`. | `npm init -y` (aceita os padrões) |
| `npm install <pacote>` | Instala uma dependência e a adiciona ao projeto. | `npm install express` |
| `npm install` | Instala todas as dependências listadas no `package.json`. | `npm install` |
| `npm uninstall <pacote>` | Remove uma dependência do projeto. | `npm uninstall lodash` |
| `npm update` | Atualiza os pacotes instalados no projeto. | `npm update` |

## 3. Ambiente Python e Gerenciador `pip`

O **pip** (*Python Package Installer*) é a ferramenta padrão recomendada para gerenciar pacotes e bibliotecas na linguagem Python.

### 3.1. Instalação e Verificação do `pip`
Normalmente já vem integrado às versões modernas do Python.

* **No Linux (Ubuntu/Debian):**
  ```bash
  sudo apt update
  sudo apt install python3-pip -y
  ```
* **Verificação da instalação:**
  ```bash
  python3 --version
  pip3 --version
  ```

### 3.2. Comandos Essenciais do `pip`

| Comando | Descrição | Exemplo de Uso |
| :--- | :--- | :--- |
| `pip install <pacote>` | Instala uma biblioteca externa. | `pip install django requests` |
| `pip install -r requirements.txt` | Instala todas as dependências listadas em um arquivo de texto. | `pip install -r requirements.txt` |
| `pip freeze > requirements.txt` | Salva o estado atual das dependências no arquivo de projeto. | `pip freeze > requirements.txt` |
