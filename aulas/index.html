📌 Regra Fundamental de IP Único

Cada equipamento em uma rede precisa ter um IP exclusivo. IPs duplicados geram Conflito de IP, interrompendo a comunicação.

🎯 Papel da Porção de Rede vs Host

Dispositivos com a mesma porção de rede comunicam-se diretamente. Dispositivos em redes diferentes necessitam de um Roteador (Gateway).

2. Máscara de Sub-rede e Notação CIDR

Como a máscara define onde termina a rede e onde começa o host.

Classful (Antigo) vs Classless / CIDR (Atual)

No modelo antigo (Classful), as redes eram presas a blocos rígidos (Classe A, B e C), provocando um enorme desperdício de endereços IP no mundo inteiro.

Modelo Prefixo Fixo / Flexível Máscaras Padrão Capacidade de Hosts Flexibilidade
Classe A (Classful) /8 fixo 255.0.0.0 16.777.214 hosts Desperdício massivo
Classe B (Classful) /16 fixo 255.255.0.0 65.534 hosts Rígido
Classe C (Classful) /24 fixo 255.255.255.0 254 hosts Pequeno para médias empresas
CIDR (Classless) Qualquer prefixo (/8 a /30) Definida pelo prefixo (ex: 255.255.255.192) Sob medida (2, 14, 30, 62, 126, 254...) Alocação Eficiente ✨

3. Algoritmo e Fórmulas de Cálculo de Sub-rede

Entenda a matemática precisa por trás de cada parâmetro de sub-rede.

PASSO 1

Identificar Bits de Host ($n$)

$$n = 32 - \text{Prefixo CIDR}$$

Como o IPv4 possui 32 bits no total, subtraindo o número de bits reservados para a rede, obtemos os bits restantes destinados aos dispositivos.

Exemplo para /26:
\(n = 32 - 26 = \mathbf{6\text{ bits de host}}\)
PASSO 2

Quantidade Total de Endereços

$$\text{Total IPs} = 2^n$$

Com \(n\) bits de host, o número de combinações binárias possíveis é \(2^n\). Este valor define o tamanho do bloco (incremento).

Exemplo para /26:
\(2^6 = \mathbf{64\text{ endereços totais por bloco}}\)
PASSO 3

Hosts Válidos / Utilizáveis

$$\text{Hosts Válidos} = 2^n - 2$$

Por que subtrair 2? O 1º endereço é reservado para a Rede e o último é reservado para o Broadcast.

Exemplo para /26:
\(64 - 2 = \mathbf{62\text{ hosts utilizáveis}}\)
PASSO 4

Tamanho do Bloco & Incremento

$$\text{Incremento} = 256 - \text{Máscara Decimal}$$

O incremento indica de quanto em quanto os endereços de rede saltam no octeto modificado.

Exemplo para /26 (Máscara 255.255.255.192):
\(256 - 192 = \mathbf{64}\) (Redes: .0, .64, .128, .192)

4. Estudo de Caso: Divisão por Departamentos

Aplicação prática do conceito de Subnetting na infraestrutura de uma empresa real.

Cenário Corporativo

Dividindo uma Rede 192.168.1.0/24 para 4 Departamentos

A empresa necessita isolar logicamente quatro setores estratégicos: RH, Financeiro, TI e Vendas.

A
Necessidade: 4 sub-redes distintas.
B
Empréstimo de Bits ($k$): Precisamos achar $k$ tal que \(2^k \ge 4\).
Como \(2^2 = 4\), devemos emprestar 2 bits da parte de host.
C
Novo Prefixo CIDR: Prefixo original \(24 + 2 = \mathbf{/26}\).
D
Máscara Resultante: 26 bits 1 em binário = 255.255.255.192.
👥

RH

Rede: 192.168.1.0/26
Hosts Válidos: 192.168.1.1 – 192.168.1.62
Broadcast: 192.168.1.63
Capacidade: 62 dispositivos
💰

Financeiro

Rede: 192.168.1.64/26
Hosts Válidos: 192.168.1.65 – 192.168.1.126
Broadcast: 192.168.1.127
Capacidade: 62 dispositivos
💻

TI

Rede: 192.168.1.128/26
Hosts Válidos: 192.168.1.129 – 192.168.1.190
Broadcast: 192.168.1.191
Capacidade: 62 dispositivos
📈

Vendas

Rede: 192.168.1.192/26
Hosts Válidos: 192.168.1.193 – 192.168.1.254
Broadcast: 192.168.1.255
Capacidade: 62 dispositivos

🚀 Benefícios Técnicos Alcançados com o Subnetting:

  • Redução drástica do tráfego de Broadcast: Os pacotes de broadcast ficam isolados dentro de cada sub-rede.
  • Maior Segurança: Regras de Firewall e ACLs podem controlar o acesso entre o setor Financeiro e os demais.
  • Organização e Gerenciamento: Cada setor possui seu próprio escopo DHCP e identificação lógica.
