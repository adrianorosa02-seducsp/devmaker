Questão 1
Qual campo do quadro Ethernet é responsável por verificar se os dados chegaram sem erros? Se não for esse campo, indique o erro.
Questão 2
Entre os protocolos CSMA/CD e CSMA/CA, qual é utilizado em redes Wi-Fi para evitar colisões, funcionando de forma preventiva?
Questão 3
Qual filtro do Wireshark permite visualizar apenas o tráfego de resolução de nomes de sites, traduzindo-os para endereços IP?

Dicas para Responder

Questão 1: O campo que verifica erros na transmissão é o FCS, que funciona como um lacre de segurança.

Questão 2: O protocolo utilizado no Wi-Fi para evitar colisões é o CSMA/CA, que funciona de forma preventiva.

Questão 3: Para visualizar apenas o tráfego de resolução de nomes, o filtro correto é "dns".
